# Healthcare Diabetes Data Analysis & Dashboard

A Python-based data analysis project using the **Pima Indians Diabetes Dataset**. The project explores health-related factors and their relationship with diabetes outcomes through data analysis, visualization, and an interactive Streamlit dashboard.

## 📌 Project Overview

This project focuses on analyzing healthcare data to identify patterns and relationships between variables such as **Glucose, BMI, Blood Pressure, Age, Insulin, and Pregnancies**.

The project includes Exploratory Data Analysis (EDA), data visualization, and introductory machine learning classification.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Streamlit
* Scikit-learn

## 📊 Dataset

The project uses the **Pima Indians Diabetes Dataset**, containing health-related measurements and a diabetes outcome column.

## 🔍 Key Features

* Data cleaning and preprocessing
* Exploratory Data Analysis
* Statistical and visual analysis
* Interactive charts and graphs
* Streamlit dashboard
* Machine learning model exploration

## 🤖 Machine Learning

The project explores classification algorithms including:

* Logistic Regression
* Decision Tree Classifier
* Support Vector Machine (SVM)

## 📈 Dashboard

An interactive Streamlit dashboard was created to make the analysis easier to understand through charts, graphs, and key observations.

## 🎯 Learning Outcomes

This project helped develop practical skills in **Python programming, data preprocessing, exploratory data analysis, data visualization, dashboard development, and introductory machine learning**.

## ⚠️ Disclaimer

This project is created for **educational and data-analysis purposes only**. It is not intended for medical diagnosis, treatment, or clinical decision-making.
